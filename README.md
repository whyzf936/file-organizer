# file-organizer

一个用 Python 编写的命令行文件整理工具。扫描目录下的文件，按类型自动归类到对应子文件夹（图片、文档、视频、音频等），让杂乱的下载文件夹恢复整洁。

## 功能特性

- 📁 按扩展名自动识别文件类型并归类（图片 / 文档 / 视频 / 音频 / 压缩包 / 代码 / 安装包）
- 🔍 **dry-run 预览模式**：先看会怎么整理，确认无误再真动手，避免误操作
- 🛡️ 同名文件自动加序号，绝不覆盖已有文件
- 📊 整理结束后输出分类统计报告
- 🧪 完整的单元测试覆盖核心逻辑

## 环境要求

- Python 3.9+（仅使用标准库，无需安装第三方依赖）

## 快速开始

```bash
# 整理当前目录
python organizer.py

# 整理指定目录（如：下载文件夹）
python organizer.py --dir D:/下载

# 先预览会怎么整理（推荐第一次使用先预览）
python organizer.py --dir D:/下载 --dry-run
```

## 运行测试

```bash
python -m unittest test_organizer -v
```


## 设计说明

- **规则与逻辑分离**：`rules.py` 只管"什么扩展名属于什么类别"，`organizer.py` 只管"怎么扫描和移动"。想新增类别（比如"字体"），只需改 `rules.py` 一个文件。
- **dry-run 设计**：`execute_move()` 接收一个 `dry_run` 参数，为 `True` 时只打印计划、不执行移动。这种"先预览、再执行"的模式在很多危险操作（批量删除、迁移）里都很常见，是一种重要的安全设计。
- **不覆盖原则**：`unique_target()` 在目标文件已存在时自动追加 `_1`、`_2` 序号，保证用户数据安全。
